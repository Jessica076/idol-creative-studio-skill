# Changelog

## v2.2.0

- Change the default sticker-sheet canvas from 4:5 to the approved 16:25 portrait ratio.
- Recommend 1600×2500 output and preserve a full, naturally spaced layout with no heavy overlap.

## v2.1.0

- Add photo-to-sticker-sheet extraction with realistic people and simplified color-block objects.
- Add opaque source-matched paper backgrounds and bilingual sticker-sheet triggers.
- Add deterministic prompt and routing tests for the hybrid visual treatment.

## v2.0.0

- Route image work through the installing user's host-provided tools instead of a maintainer API key.
- Add bilingual triggers, skill-picker metadata, offline prompt generation, and offline tests.
- Add identity-preservation QA, print-safe workflows, and fan-made rights guardrails.
- Rewrite the GitHub installation and usage documentation.

## v1.0.0

- Add wallpaper, sticker, and photocard workflows with four style guides.

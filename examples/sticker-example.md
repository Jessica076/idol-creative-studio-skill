# Sticker Generation Example

## User Input

Image:

An idol portrait photo.

Request:

Create a collectible sticker.

Style:

Cute chibi.


## AI Workflow

1. Remove background.
2. Convert image into sticker style.
3. Add clean white outline.
4. Add subtle shadow.
5. Prepare transparent background.


## Design Direction

Style:

- Cute expression
- Soft colors
- Merchandise feeling


## Expected Output

A printable sticker design:

- Transparent background
- Clear outline
- High quality
- Recognizable idol features

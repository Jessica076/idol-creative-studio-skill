# Wallpaper Generation Example

## User Input

Image:

A concert stage photo of an idol.

Request:

Create a premium smartphone wallpaper.

Style:

Dark luxury concept.

Device:

iPhone


## AI Workflow

1. Analyze the idol position and lighting.
2. Preserve facial identity.
3. Extend background naturally.
4. Create cinematic atmosphere.
5. Optimize composition for phone screen.


## Design Direction

Visual style:

- Black and silver color palette
- Concert lighting
- Premium album concept
- Minimal typography


## Expected Output

A high-resolution smartphone wallpaper with:

- Clear idol focus
- Balanced composition
- Professional K-pop album aesthetic

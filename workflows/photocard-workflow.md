# Photocard workflow

1. Select a 2.5:3.5 portrait ratio and determine whether the user wants front only or separate front/back files.
2. Keep important faces and text at least 3 mm inside the trim edge. Add 3 mm bleed for professional printing when requested.
3. Build the front around one identity-preserving portrait, restrained typography, and a coherent album-style motif.
4. For the back, use matching colors plus optional user-provided message, date, or social handle. Never fabricate a signature.
5. Add a subtle `FAN MADE` or `UNOFFICIAL` mark when the result could be confused with official merchandise.
6. Generate front and back separately; do not place both on one canvas unless a print sheet is requested.
7. Check identity, spelling, orientation, safe margins, bleed, and exact ratio.

Deliver PNG files by default. Recommend a print proof before bulk production.
